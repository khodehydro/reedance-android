# وضعیت تحویل

## پیاده‌سازی‌شده در کد (نیازمند build و تست دستگاه)

- پروژهٔ Kotlin/Compose، Gradle Wrapper، SDK حداقل ۲۶، مخزن مایکت در اولویت، CI debug.
- یک اسپلش سیستم با لوگوی اصلی و انتظار تا آماده‌شدن داده؛ اسپلش دوم Compose حذف شد.
- ستاپ اولین اجرا با زبان English/فارسی، جهت سراسری و جهت مستقل متن آموزشی؛ تنظیمات DataStore.
- خانه/کشف بدون جست‌وجو، فیلترهای کپسولی و پرچم زبان، کاورهای lazy با کش و decode در IO، آیکن‌های Uicons وب.
- انتقال تمام داده‌های استارتر en/es/ko؛ حروف، راهنمای فارسی، صدا، گرامر/جدول، واژه، تمرین و پیشرفت مستقل هر زبان.
- کپی اتمیک دموی محلی به فضای خصوصی و بررسی SHA صوت؛ جداسازی debug از release.
- سرویس Media3 و MediaSession، پخش/مکث/seek/پرش/repeat/mute، حفظ موقعیت، مینی‌پلیر پس از شروع پخش.
- صفحهٔ آهنگ بدون ناوبری عمومی؛ هدر ثابت و نوار پخش هنگام اسکرول؛ سه شیوهٔ لیریک و پنجرهٔ واژه.
- نکته‌ها، جدول‌ها، لغت، اصطلاح و جمله از JSON منتقل‌شده به قرارداد v1؛ نشان‌ها در Room.
- صفحهٔ آزمون بدون پلیر/ناوبری عمومی؛ چهار قالب choice/match/order/typing، کامل‌بودن پاسخ، توضیح و نتیجه.
- اتصال غلط‌ها به کارت‌های مرتبط؛ match فقط جفت غلط؛ نرمال‌سازی NFC و حفظ accent؛ نتیجهٔ هر سؤال با نسخه و زمان.
- لایتنر با ۲/۴/۸/۱۶ روز و فراموشی یک دقیقه‌ای؛ مرور کارتی و پرسشی؛ کتابخانهٔ عبارت‌ها.
- پروفایل مهمان، روشن/تاریک/سیستم، سه اندازهٔ متن، کاهش حرکت، حذف فایل با حفظ پیشرفت، امتیاز محلی و share.
- primitiveهای بررسی امضای Ed25519، UTF-8/JSON با رد کلید تکراری، Base64URL canonical، ضد rollback و AES-GCM fixture با AAD اصلی.

## اجرا و بررسی انجام‌شده در این محیط

- `scripts/test_assets.py`: **۱۳ تست پاس شد**.
- parse نحوی تمام فایل‌های Kotlin/Kotlin DSL با tree-sitter: بدون خطای نحوی. این **type-check یا کامپایل Kotlin نیست**.
- بررسی ZIP معتبر بودن Gradle Wrapper، XMLهای Android و whitespace/diff.
- تلاش برای `:app:testDebugUnitTest :app:assembleDebug` در ابتدای اجرا با خطای نبود `JAVA_HOME/java` متوقف شد؛ **APK ساخته نشده است**.
- unit testهای Kotlin، instrumented testها و workflow نوشته شده‌اند اما **اجرا نشده‌اند**.

## باقی‌مانده؛ مانع اعلام کامل‌بودن محصول

1. build/lint واقعی Android و رفع خطاهای احتمالی dependency/API/type-check، اجرای روی API 26 و دستگاه جدید، rotation/process-death و تست سرویس پس‌زمینه.
2. مقایسهٔ تصویری با React در دو زبان، دو تم و سه اندازهٔ متن؛ طرح فعلی اقتباس بومی است، نه ادعای pixel-perfect. آیکن‌ها اکنون وکتورهای همان Uicons Regular Rounded وب هستند. بعضی جزئیات مانند چیدمان تبلت و فراخوان پایان خودکار آهنگ هنوز برابر مرجع نیستند. حرکت‌های دسته‌کارت از زمان‌بندی مرجع استفاده می‌کنند، ولی چرخش/ارتقای لایه‌ها هنوز تطبیق کامل ندارد.
3. مسیر تولیدی کامل: bootstrap واقعی → fetch manifest با allowlist و ETag معتبر → WorkManager، progress/cancel/retry و محدودیت فضا → دانلود streaming `.part` → تأیید امضا/هش/GCM → ZIP سخت‌گیر با کنترل local/central directory و bomb/symlink/CRC → schema و قواعد معنایی کامل → نصب transaction با pointer نسخه و crash recovery. **این مسیر هنوز متصل/پیاده‌سازی کامل نشده است**. وابستگی‌های OkHttp/WorkManager رزرو شده‌اند؛ وابستگی داشتن به معنی downloader موجود نیست.
4. verifier فعلی فقط primitive پروتکل و fixture کوچک (حداکثر ۸MiB) است، نه مصرف‌کنندهٔ عمومی بستهٔ ۲۵۶MiB. از آن برای دادهٔ تولیدی یا ورودی دلخواه استفاده نکنید. هیچ راه ورود فایل دلخواه به UI باز نیست.
5. مهاجرت نسخه‌های محتوایی، aliasها و آرشیو آیتم‌های حذف‌شده، registry واژگان چندآهنگی، migration/restore تست‌شدهٔ Room و نمایش تاریخچهٔ کامل آزمون‌ها. فعلاً تنها دموی محلی نسخهٔ ۱ مصرف می‌شود.
6. تست TalkBack، semantics سرستون/سرسطر جدول، کنتراست، اندازهٔ هدف لمس و فونت Hangul روی دستگاه واقعی. تنظیم اولیهٔ بزرگ‌نمایی سیستم حفظ می‌شود و مقیاس اپ روی آن اعمال می‌گردد.
7. دریافت URL/کلیدهای تولید از مالک خارج Git، مجوز فایل‌ها، ممیزی امنیتی، تست بستهٔ تازهٔ Windows و v1→v2 و فعال‌سازی انتشار.

هیچ حساب، پرداخت، آپلود ابر یا همگام‌سازی‌ای اضافه نشده است. طبق مستند مرجع اینها در v1 نیستند. کلیدهای fixture و مجوزهای ادعایی را نباید تولیدی دانست.

به‌روزرسانی رابط: `UI_REFRESH.md`؛ حذف transition کل صفحه برای پاسخ‌گویی سریع‌تر، حفظ state صفحه، وزیرمتن با فایل بولد واقعی و برند Manrope ExtraBold. بهبود FPS/زمان ناوبری هنوز روی دستگاه اندازه‌گیری نشده است.

پیگیری ناوبری و فیلتر: پرچم دایره‌ای، ورود/خروج/جابه‌جایی متحرک کارت، دانلودشده‌های واقعی، آیکن Solid برای تب فعال، منوی کپسولی جمع‌شونده و نوار سیستم شفاف اضافه شد. جزئیات رفتار و محدودیت آزمون دستگاه در UI_REFRESH.md آمده است.
