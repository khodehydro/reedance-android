# Floating lyrics (Android 8–15, API 26–35)

Floating lyrics is off by default. Release builds require verified Premium entitlement; debug builds temporarily allow background playback and floating lyrics without a subscription for device testing. Floating lyrics still requires the user-granted Android “display over other apps” permission. It can be enabled from My Space. On some Android versions the system opens a list of apps instead of Reedance’s permission directly; select Reedance in that case. The permission is never requested at startup. The user can turn the feature off in Reedance or revoke the permission in Android settings.

The Media3 playback service owns the small `TYPE_APPLICATION_OVERLAY` window and syncs it to the playing song’s local lyric timestamps. There is no new foreground-service type or external-app monitoring. Touch outside the window remains available to the other app. The card has a close button (dismisses for the current time away) and an original / line-by-line / word-by-word mode button. Translations depend on the installed lesson data. The card hides when playback pauses/ends, the app comes back to the foreground, Premium is lost, permission is revoked, the device locks, or the service stops.

Android and OEM policies can deny or hide overlays, especially on protected screens, restricted profiles, or in battery-restricted builds. The app does not bypass these restrictions. Release validation should cover at least API 26, 30, 31, 34 and 35 and representative Pixel/Samsung/Xiaomi devices: permission grant/denial and revocation, playback/seek from the media notification, screen lock, rotation, return to the app, and close/mode controls. Use a debug build to test without a subscription. This exception does not activate Premium or unlock any paid lesson.
